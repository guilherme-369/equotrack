# EquoTrack Design System

## Design direction

The interface should feel:

- professional;
- clinical;
- calm;
- human;
- restrained;
- functional;
- contemporary.

Prioritize information hierarchy and usability over visual spectacle.

EquoTrack should look like a professional working tool before it looks
like a portfolio project.

## Cards

Default:

- white background;
- 1px border;
- 8px radius;
- no shadow.

Use cards only when they provide meaningful grouping.

Do not place every section inside a card.

## Buttons

Primary:
primary background with white text.

Secondary:
white or transparent background with border.

Destructive:
danger styling only when semantically necessary.

Typical height:
36–40px.

## Tables

Prefer:

- clean rows;
- subtle horizontal separators;
- minimal vertical borders;
- restrained hover state;
- compact status indicators.

The entire practitioner row may be clickable.

## Forms

Group fields using:

- headings;
- spacing;
- subtle dividers.

Do not create an independent card for every form group.

Desktop forms may use two columns where appropriate.

Long narrative fields should remain full width.

## Longitudinal timeline

The practitioner history timeline is a distinctive EquoTrack component.

Prioritize:

- date;
- session number;
- structured observations;
- narrative observations;
- chronological hierarchy.

Do not transform clinical evolution into arbitrary scores or percentages.

## Responsive behavior

Breakpoints:

Mobile:
< 768px

Tablet:
768px–1024px

Desktop:
> 1024px

Desktop uses sidebar + content.

Mobile replaces the persistent sidebar with compact navigation.

Avoid unnecessary horizontal scrolling.

## Motion

Only use motion for functional feedback such as:

- hover;
- focus;
- mobile navigation;
- dropdown;
- modal.

Preferred transition duration:
150–200ms.

Do not add decorative entrance animations.

## Forbidden patterns

Do not use:

- gradients;
- glassmorphism;
- excessive shadows;
- huge typography;
- decorative charts;
- floating cards;
- excessive pill-shaped elements;
- random accent colors;
- decorative illustrations;
- meaningless statistics;
- unnecessary animation;
- dashboard filler;
- cards around every content group.

Visual restraint is intentional.
